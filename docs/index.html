  1. Генерируем ключ
  2. Подключаем к sourcecraft
  3. Клонируем репозиторий

Генерируем ключ

Для начала необходимо обзавестись программой gitBash, если вы этого ещё не сделали.

Здесь можно скачать gitBash.

Дело в том, что исторически архитектура git была разработана под linux. Linux внутренне устроен иначе чем windows, и, что очевидно, языки терминала windows и linux существенно различаются. Команды git - это команды linux.

Заходим в gitBash от имени администратора, вводим команду:

gitBash
$ ssh-keygen

В самом начале - вводим своё название для файла, если нас не устраивает системное. Иначе - наживаем enter, тогда файл получит название в духе id_ed25519. Когда он попросит кодовое слово - просто нажимаем enter, если, конечно, вы не хотите ставить пароль.

В результате в директории C:\Users\<имя пользователя>\.ssh появятся 2 файла: один без расширения, один - с расширением .pub. Файл без расширения - приватный ключ, его нельзя показывать никому. Файл с расширением .pub - публичный ключ. Это почти как RSA на алгебре, только круче, потому что алгоритм сложнее.

Сразу после нужно создать в той же директории файл с названием config без расширения (проверьте, что его действительно нет, а оно не скрыто системой!). В этот файл скопируйте текст ниже, заменив всё, что нужно заменить внутри угловых скобок:

common text
Host ssh.sourcecraft.dev
    IdentityFile C:/Users/<имя пользователя>/.ssh/<название файла секретного ключа, по умолчанию - id_ed25519>
    IdentitiesOnly yes

Подключаем в sourcecraft

Далее нужно перейти в sourcecraft и сохранить там наш публичный ssh-ключ: левая панель > доступ > SSH-ключи. В правом верхнем углу - кнопка "+ Новый SSH ключ". Нажимаем её, придумываем название ключу и добавляем публичный ключ из нашего файла id_ed25519.pub (есть кнопка загрузить из файла).

Переходим к репозиторию c дз, там жмём "Клонировать" в правом верхнем углу, в выпадающем меню будет 3 ссылки. Копируем ссылку для SSH и перемещаемся в IntellyJ IDEA.

Клонируем репозиторий

В IDE переходим в верхней панели: file > new > new project from version control... Откроется вспылвающее окно. В поле URL вставляем скопированную ссылку, нажимаем enter до упора. Готово.

Когда понадобится сделать коммит, посмотрите на левую узкую панель. Там несколько вертикальных иконок, вторая из них - commit. Там просто выбираем нужные файлы, нажимаем commit and push, ждём пока загрузится. Не забудьте написать сообщение коммита в нижнем левом углу.
